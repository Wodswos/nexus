# Nexus UI 专项改版手册（Refactor Playbook）

执行顺序：P0 → P1 → P2。长期约束与冲突裁决见 [UI 工程规范](UI_ENGINEERING_SPEC.md)。


改版按 ROI（视觉提升 / 改动成本） 分为三个阶段，严格按顺序推进，避免在底层 Token 未统一前盲目调组件。

## 阶段一（P0）：止血与降噪——重构全局色彩与边框

目标：消除“拼凑感”和“重线框感”。

| 改造项 | 现状问题 | 目标修改 | 验收标准（DoD） |
| --- | --- | --- | --- |
| 1. 统一中性灰基底 | 侧边栏、按钮、卡片、导图节点各自使用不同色温的灰/蓝/棕。 | 全站切换为单一冷灰体系（Slate 色系），彻底清除无依据的硬编码灰值。 | 任意两个相邻容器的边框与背景色均来自同一色温表。 |
| 2. 确立唯一强调色 | 灰绿 Logo、浅蓝筛选态、深藏青根节点三色并存。 | 选定唯一主强调色（建议方案 A：极简深炭黑 #18181B；方案 B：森林绿 #2E6F5E），所有高亮与核心节点向其收敛。 | 全屏非语义状态色（非红/黄/绿报警色）的彩色色相 \le 1 种。 |
| 3. 弱化所有分割线 | 顶部与侧边栏实心灰线过重，切割感强。 | 将所有布局分割线替换为 1px solid rgba(15, 23, 42, 0.08)，组件描边替换为 rgba(15, 23, 42, 0.10)。 | 眯眼看页面时，分割线退居视觉背景，不再抢夺文字注意力。 |

## 阶段二（P1）：骨架重塑——压缩 Chrome 密度与修正比例

目标：从“放大 125% 的松散网页”收敛为“高精度桌面效率工具”。

### 1. 顶部三层结构合并为两层
  ⚬ 现状：我的工作空间、AIDD & Bio + 视图切换、全部 / 推进与逾期... 占据三行独立高度且每行底部均有横线。
  ⚬ 改法：
    ⚬ 删除 我的工作空间 独立顶栏，将其上移至左侧边栏顶部作为 Workspace 切换器，或作为 12px 灰色面包屑置于 AIDD & Bio 上方（间距 2px）。
    ⚬ Header 主行（高 52px）：左侧放标题 AIDD & Bio（18px, weight: 600, letter-spacing: -0.02em），右侧放视图切换分段控制器。
    ⚬ Filter 副行（高 40px）：取消与 Header 之间的横线，仅保留 Filter 行底部的全局画布分割线；筛选项字号降为 13px，右侧计数（如 0、20） 用等宽数字小徽章包裹。
### 2. 左侧边栏重构（宽 220px–240px）
  ⚬ + 添加任务 按钮：左右保留 12px 安全边距；高度压至 34px；白底 + 微弱边框 + 0 1px 2px rgba(0,0,0,0.04) 投影；快捷键 N 改为 `<kbd>` 胶囊样式。
  ⚬ 导航列表项：单行高 32px，项间距 2px，字号 13.5px，图标 16×16px（线宽 1.5px），图标与文字间距 8px。
  ⚬ 分组标题（快捷视图）：字号 12px，--text-muted，上边距 20px、下边距 6px。
### 3. 视图切换分段控制器（列表 / 导图）
  ⚬ 容器高 32px，padding: 2px，圆角 8px，背景 #F1F5F9。
  ⚬ 激活项圆角 6px（严格满足 外圆角 8 = 内圆角 6 + 内边距 2），背景 #FFFFFF，投影 0 1px 2px rgba(15, 23, 42, 0.08)。

## 阶段三（P2）：画布升级——统一导图景深与线条

目标：让导图节点与外围 UI 处于同一物理空间。

1. 根节点（AIDD & Bio）：去除厚重单层黑影，改为双层弥散阴影；内部标题 14px/600，进度 1/21 完成 降为 11.5px 并配 2px 高微型进度条。
2. 子节点（Design）：底色改为纯白 #FFFFFF（脱离发灰底色），加 1px 浅边框与 Elevation-1 轻投影。
3. 连接线：颜色改为 #CBD5E1，线宽 1.5px；将直角折线改为三次贝塞尔曲线（水平切线进出），选中路径高亮为强调色。
4. 画布底纹：背景叠加极浅点阵（1px 圆点，#E2E8F0，间距 20px），增强无限画布的空间锚定感。
