# Nexus 交互设计

更新日期：2026-11-10。本文记录当前软件的交互约定，作为后续迭代和回归验收的基线。移动端安全区、尺寸和原生手势详见 [移动端 UI 设计](MOBILE_UI_DESIGN.md)；构建、数据与发布流程见 [运行手册](../RUNBOOK.md)。

跨视图多选及批量时间、优先级等操作的后续方案见 [Task 多选与批量操作设计](TASK_BATCH_OPERATIONS.md)。该文明确区分已有能力和待实施行为，尚未实施的方案不属于本文现状承诺。

导图与列表的多选工具条已提供「时间」「优先级」：日期可分别不修改、设置或清除，也可整体按天移动；优先级统一设为 P0–P3。面板显示混合值和修改数量，项目／分组不参与，一次应用、一次撤销。取消面板不写入。
导图框选拖动期间显示范围框，松开后只保留各节点的选中标记，不保留外围虚线或拦截点击的遮罩。右击已选节点或有选区的画布空白处打开整批菜单；右击未选任务只操作该项，不携带旧选区。
多选菜单提供时间、优先级、转为分组／Task、折叠／展开全部子任务和删除；创建子任务、打开详情、跳转视图仅在单项菜单出现。类型转换仅修改所选的普通任务／分组，保留内容、日期、优先级及层级；普通顶层项转为分组不变成项目，项目根节点不参与转换。折叠／展开遍历全部所选分支的子树，仅修改视图状态。甘特、四象限与日历的统一多选仍为后续工作。

## 1. 产品目标与信息结构

Nexus 将项目结构、依赖、排期与执行记录放在同一套任务数据上，让用户从全局找到正在推进的工作，再直接修改任务。视图切换改变任务的呈现方式，不复制任务。

桌面使用左侧导航、顶部工作区工具栏和主内容区。侧栏包含当前任务、收集箱、可折叠的项目目录和快捷视图，以及复盘、专注、习惯、回收站等入口。设置、用户名与同步状态收在侧栏底部同一行。侧栏可调宽，移动端通过菜单和边缘手势展开。

项目根节点是结构节点。项目目录进入的就是该根节点下的工作区，不额外再嵌套一个同名项目。项目名称可编辑，支持拖动排序、归档与删除；拖动柄在名称左侧，菜单按钮在选中背景内悬浮显示，也支持右键菜单。删除项目先确认，已删除内容从回收站查看和恢复。

快捷视图是用户保存的工作区配置，包含视图类型、项目范围、时间范围与任务筛选。可新增、编辑、排序、移除，目录独立折叠；移除快捷视图不删除任务。全局预置包含「本月日历」。

## 2. 视觉语言与操作反馈

- 使用统一的背景、表面、边界、正文、辅助文字、强调色和危险色变量；浅深主题保持相同几何结构。
- 将高频的任务、日期和视图操作留在主工具栏，低频设置放进明确的菜单。辅助说明使用可展开列表，避免长期占据画布。
- 文字优先，图标使用一致尺寸与笔画。状态、悬浮和选中不能只靠颜色区分；可点击图标提供名称、焦点和提示。
- 导图节点默认霞鹜文楷、16 px、加粗，分支向右展开。用户可以设置背景、边框、文字、字号、字体与手绘外观，多选可批量调整，字体资源与授权随仓库维护。
- 导图悬浮使用半透明外框，选中框与悬浮框占用相同尺寸；切换选中立即反馈，不触发整图重新测量或重置镜头。
- 下拉控件保留箭头与边框之间的空间；长文本可截断，详情仍可查看完整内容。保存、离线和错误反馈保持可见。

## 3. 工作区、视图与筛选

五个视图统一顺序为 **列表、导图、四象限、甘特图、日历**。「时间线」在用户界面中称为「日历」。日历是工作区视图；侧栏的日历入口使用快捷视图机制。

| 入口／操作 | 默认与记忆规则 |
| --- | --- |
| 当前任务 | 默认本周甘特图，可选择今天、本周、本月或自定义区间 |
| 首次进入项目 | 列表；导图、列表、四象限默认可查看全图；时间视图缺少区间时默认本周 |
| 项目之间切换 | 分别记住每个项目最后使用的视图，A 的偏好不改变 B |
| 显式切换视图 | 保留当前工作区的时间与任务筛选，不在切换时重置它们 |
| 快捷视图 | 打开保存的视图、范围与筛选，可在当前页面临时调整 |
| 隐藏已完成 | 勾选框一次点击切换，偏好随账号保存；手机放在更多菜单 |

所有视图共用前置按钮「全部／当前工作／本周／逾期」及完整筛选，支持任务状态、优先级、标签和日期区间。

- **当前工作**：手动进行中的任务，以及未完成且已经逾期的任务。
- **进行中**：任务的执行状态；时间窗也会产生运行中、未开始或逾期等展示提示，不等同于「本周」。
- **本周**：明确的本地周区间，遵循账号每周开始日设置。
- 当前任务常规筛选隐藏无开始／截止日期的历史待办，并保留必要祖先上下文。已有日程关联可以作为日历时间块继续访问。
- 项目和有效快捷视图保留未排期任务。结构节点只表达组织关系，不参与完成态、优先级、排期或四象限。
- 新任务继承明确的筛选条件和日期上下文；清除日期同时移除开始与截止，不保留虚假的本周安排。

## 4. 导图

### 点击、选择与编辑

普通单击默认选中任务并打开详情。右上角「任务交互设置 → 单击任务打开详情」可关闭自动打开，偏好随账号同步。关闭时单击仍选中任务；详情图标、选中工具条的「详情」和 ⌘／Ctrl + Enter 仍可主动打开。

详情已经打开时，普通点选其他任务直接切换内容。双击进入标题编辑；输入法组合输入期间不提前提交。点击完成图标、折叠按钮等节点控件只执行自身操作。拖动节点、多选与框选不自动打开详情。

| 操作 | 行为 |
| --- | --- |
| 空白处单击 | 清除选择、收起详情并保存已有文字草稿 |
| 空白处拖动 | 框选节点；松开后范围框消失，保留各节点选中标记 |
| ⌘／Ctrl 或 Shift + 点选 | 多选；详情收起，保留批量样式与右键操作 |
| ⌘／Ctrl + A | 选择当前图中已展开节点；编辑文字时只全选文字 |
| 双击节点 | 编辑标题；输入框宽度随文字更新 |
| Tab／Enter | 添加子任务／同级任务；项目根节点的 Enter 添加子任务 |
| Delete | 删除所选任务；项目删除仍经确认 |
| ⌘／Ctrl + Z、⇧ + ⌘／Ctrl + Z | 撤销、重做 |

### 画布与结构

双指或滚轮平移，捏合缩放；鼠标中键或右键可拖动画布。空闲时保持正常指针。右下角显示缩放百分比、缩放、回根节点、全图与画布配置；画布配置包含连线样式和本浏览器按账号保存的平移速度。右上角的任务点击设置与右下角的画布设置分别命名。

大图初次打开优先显示根节点附近，后续按账号和项目记住位置与缩放。只有明确的任务定位请求才重新居中目标，普通选中、备注保存、日期修改不移动画布。切回页面、字体加载和容器尺寸恢复后需要重新确认节点及连线几何，不能依赖手工刷新。

拖到节点中部表示挂为子任务；上下边缘表示同级前后插入；全局导图可拖到用户名根节点移至顶层。当前导图连线表达父子层级；跨分支 DAG 依赖尚无独立编辑交互。筛选强调当前工作时保留全局位置，不任意交换节点位置。

## 5. 列表与四象限

列表保持紧凑行结构。选择后大屏右侧停靠详情，小屏使用统一的底部详情。拖动时展示目标位置与层级提示：行中部关联、边缘排序，向左移出层级。中文新建、回车确认、空白取消与已有任务编辑采用一致的输入法规则。

四象限显示任意层级的任务，按重要和紧急两个维度组织。拖动到另一个象限改变优先级；点击打开详情，双击象限空白新建。常规每象限显示前 24 项；明确跳转定位到更后面的任务时额外显示目标，不因展示限量丢失定位。

## 6. 甘特图

任务树位于左侧，时间轴位于右侧；名称列可调宽，任务条与名称中心对齐。结构节点只作分组行，自身不画排期条。

- 拖整条平移；拖左右端分别修改开始／截止，按 5 分钟吸附。只设一端的单日任务，拖另一端不能无故改变原有时间。
- 行内空白拖出区间可排期；项目的未排期任务可从下方拖入时间轴。取消拖动不写入日期。
- 条色由优先级决定，完成态使用完成色；调整日期不能把未完成任务变为不同深浅的状态色。
- 触控板水平滑动按当前区间跨度翻页，吸收同一次手势的惯性，避免一次手势翻多页；拖条、调整名称列和输入时不触发翻页。
- 点击任务名称或进度条打开统一详情；右击名称、条或轨道打开该任务菜单。

## 7. 日历

日历按所选区间展示日、周或月。可查看任务开始／截止标记与关联日程；没有日期的项目任务保留在未排期区域。

月历单元格根据可用高度显示尽可能多的条目，剩余内容显示「还有 X 项」。点击后弹出当天全部条目的紧凑可滚动列表。点击任务打开详情，点击日期或独立日程查看对应日期。

点击日期空白创建当天任务，配置并确认后才写入。如果已有新建提示，再次点击任意空白只取消当前提示；下一次独立点击才在新位置开启创建。拖动已有条目可改期，取消新建不产生空任务。

任务条目提供右键任务菜单，包括日／周／月、当天展开列表和未排期区域。独立日程保持自身操作语义。

## 8. 统一任务详情

导图、甘特图、四象限、日历、当前任务与快捷视图使用同一 `TaskInspector` 内容。桌面默认以右上角非模态卡片承载；若会遮挡刚点选的分支，则在画布左侧打开，并为底部操作条留出空间，继续允许操作背景任务；列表大屏保留右侧紧凑停靠格式。移动端使用有遮罩的底部面板，但字段顺序和操作与桌面一致。

从上到下为：详情标题与保存状态、**跳转到**、祖先路径、任务标题／完成、日期／优先级／状态、描述、子任务、tmux／Agent／Note 资源。底部固定「添加子任务」和「更多设置」；更多设置包含节点类型、标签、专注统计／入口、删除／恢复和创建时间，不再次打开第二套详情。

详情切换复用面板，不反复关闭再播放开场动效。切换后重置正文滚动和未提交的辅助输入状态，保存当前任务的标题／描述。关闭、点击空白、视图跳转、下拉关闭均提交文字草稿；旧保存完成后的关闭回调不能误关新选中的任务。保存失败时保留详情并显示错误。

手机打开详情只聚焦面板，不自动聚焦标题或弹键盘。正文到顶才能下拉收起，距离不足回弹；输入、文字选择、按钮操作、横向或多指手势不触发关闭。

## 9. 跳转到视图

详情顶部明确标注「跳转到」，提供所属项目／任务分支的五个视图快捷入口。右击任务后，通过「跳转到视图」选择：

| 分组 | 行为 |
| --- | --- |
| 所属项目／任务分支 | 列表、导图、四象限、甘特图、日历；没有项目的独立任务使用自身根分支 |
| 当前任务 | 进入左侧全局当前任务工作区，默认甘特图；未排期目标临时使用列表定位 |
| 快捷视图 | 列出账号保存的快捷视图；跨项目、不支持结构节点等无有效目标的选项禁用 |

跳转不复制任务、不改任务的排期、状态和层级。离开前保存未失焦的文字草稿，再进入目标工作区，展开祖先、选中或高亮任务并滚动／居中。隐藏已完成偏好保持不变；明确定位可以临时展示该目标。修改筛选、时间区间或完成显示时清除临时定位。

快捷视图保留原有筛选和配置；时间画布不包含目标日期时在 URL 中临时改为目标附近的区间，不改写快捷视图定义。未排期任务跳往有限时间视图时使用列表，避免为显示而补写日期。结构节点仅提供列表和导图入口，任务专属视图不伪造条目。

右键批量菜单中的跳转以被右击的任务为定位目标，不批量跳转；数据变更操作仍按已有多选集合执行。子菜单内容可滚动，位置避让窗口边缘；Esc 或点空白关闭。

## 10. 习惯、复盘与专注

习惯每项占一行，点击展开近期打卡热力记录，再点收起；同一时刻只展开一项。创建后可编辑，支持拖动排序与按提醒时间排序。每日多次目标保留 `已完成／目标` 数字，并按比例填充打卡标记；可设置多个时间槽，也可关闭提醒。

应用内习惯提示支持去打卡、延后与关闭本次，空闲时自动淡出；关闭当前提示不打卡、不关闭后续提醒。iPhone 原生通知的授权、排程与点击归属见移动端文档。

复盘既是推进前的计划，也是推进后的回顾；日报／周报中记录计划、实际进展、阻力、解决办法与下一步。默认每天 21:30、周日 20:00 提醒，可在设置调整。草稿随账号同步，完成复盘时保留当期事实快照。

专注可关联任务，保留时长与中断记录。任务中的 tmux、Agent、Note 使用同一资源组件，按独立区域组织；终端权限以当前账号和服务器配置为边界。

## 11. 数据与交互验收

同步、导出／导入与离线编辑必须保留账号隔离、任务 ID 与历史记录。筛选、导航偏好和 UI 更新不得清空数据卷或浏览器数据库。Agent REST API／Swagger 文档属于外部操作入口，不能让页面跳转隐式修改任务。

| 场景 | 必须满足 |
| --- | --- |
| 导图点选／框选／多选／拖动 | 默认详情与开关生效，控件和手势不误触发；镜头、连线稳定 |
| 各视图打开与切换详情 | 同一内容结构，连续切换不丢草稿、不关闭新详情，不叠加另一套面板 |
| 项目五视图／当前任务／快捷视图跳转 | 目标可见，祖先展开，过滤与完成偏好可恢复，不改任务日期 |
| 远期／逾期／未排期／已完成／结构节点 | 明确各自的可达目的地，不能跳到空白画布后丢失任务 |
| 320／390 px 与移动键盘 | 工具栏和详情无页面横向溢出，打开详情不弹键盘，正文滚动和下拉正确 |
| 项目与习惯改动 | 创建、编辑、排序和删除反馈明确；取消不生成空内容 |
| 发布 | 独立临时实例回归；完整备份、保留回滚镜像；生产只读验证 |

主要实现：`TasksPage`、`TaskMenu`、`TaskInspector`、`TaskSheet`、`taskNavigation`、`useTaskTextDraft` 与各视图。后续改变本约定时同步更新本文与移动端文档。
