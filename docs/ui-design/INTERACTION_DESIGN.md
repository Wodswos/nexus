## 1. 产品目标与信息结构

Nexus 将项目结构、依赖、排期与执行记录放在同一套任务数据上，让用户从全局找到正在推进的工作，再直接修改任务。视图切换改变任务的呈现方式，不复制任务。

桌面使用左侧导航、顶部工作区工具栏和主内容区。侧栏包含当前任务、收集箱、可折叠的项目目录和快捷视图，以及复盘、专注、习惯、回收站等入口。设置、用户名与同步状态收在侧栏底部同一行。侧栏可调宽，移动端通过菜单和边缘手势展开。

项目以独立的根身份组织 TODO 任务与文本节点。项目目录进入的就是该根节点下的工作区，不额外再嵌套一个同名项目。项目名称可编辑，支持拖动排序、归档与删除；拖动柄在名称左侧，菜单按钮在选中背景内悬浮显示，也支持右键菜单。删除项目先确认，已删除内容从回收站查看和恢复。

快捷视图是用户保存的工作区配置，包含视图类型、项目范围、时间范围与任务筛选。可新增、编辑、排序、移除，目录独立折叠；移除快捷视图不删除任务。全局预置包含「本月日历」。

## 2. 视觉语言与操作反馈

- 使用统一的背景、表面、边界、正文、辅助文字、强调色和危险色变量；浅深主题保持相同几何结构。
- 将高频的任务、日期和视图操作留在主工具栏，低频设置放进明确的菜单。辅助说明使用可展开列表，避免长期占据画布。
- 文字优先，图标使用一致尺寸与笔画。状态、悬浮和选中不能只靠颜色区分；可点击图标提供名称、焦点和提示。
- 导图节点默认霞鹜文楷、16 px、加粗，分支向右展开。用户可以设置背景、边框、文字、字号、字体与手绘外观，多选可批量调整，字体资源与授权随仓库维护。
- 导图悬浮使用半透明外框，选中框与悬浮框占用相同尺寸；切换选中立即反馈，不触发整图重新测量或重置镜头。
- 下拉控件保留箭头与边框之间的空间；长文本可截断，详情仍可查看完整内容。保存、离线和错误反馈保持可见。

## 3. 工作区、视图与筛选

五个视图统一顺序为 **列表、导图、四象限、甘特图、日历**。「时间线」在用户界面中称为「日历」。日历是工作区视图；侧栏的日历入口使用快捷视图机制。

| 入口／操作 | 默认与记忆规则 |
| --- | --- |
| 当前任务 | 默认本周甘特图，可选择今天、本周、本月或自定义区间 |
| 首次进入项目 | 列表；导图、列表、四象限默认可查看全图；时间视图缺少区间时默认本周 |
| 项目之间切换 | 分别记住每个项目最后使用的视图，A 的偏好不改变 B |
| 显式切换视图 | 保留当前工作区的时间与任务筛选，不在切换时重置它们 |
| 快捷视图 | 打开保存的视图、范围与筛选，可在当前页面临时调整 |
| 隐藏已完成 | 勾选框一次点击切换，偏好随账号保存；手机放在更多菜单 |

所有视图共用前置按钮「全部／当前工作／高优／待分级／本周／逾期」及完整筛选，支持任务状态、优先级、标签和日期区间。

普通新任务默认按 P3 处理，导图添加子任务与同级任务均采用此默认。显式优先级筛选、四象限创建和快速输入中的优先级标记作为明确选择。P3 使用青绿色。尚未主动分级的普通任务使用空心圆，确认 P3 后使用实心圆。「待分级」显示当前工作区中待确认的未完成任务及数量，支持批量选择 P0–P3。「高优」集中显示未完成的 P0／P1 任务并启用优先级排序。

列表与甘特图可选择手动顺序或优先级排序，选择随 URL 和快捷视图保存。优先级排序按 P0–P3 排列，已完成任务靠后。包含高优子任务的分支提前，父任务仍位于子任务上方。同优先级按截止时间与手动顺序排列。月历每天的条目与日历未排期任务默认采用优先级顺序，日／周视图保留时间位置。

- **推进与逾期**：已到开始时间的进行中任务，以及未完成且已经逾期的任务。
- **进行中**：未完成任务到达开始时间后自动进入，截止时间到达后归为逾期；未来开始时间为未开始，仅设置未来截止时间仍为待办。状态展示和五视图筛选使用同一规则；没有开始时间的历史 `doing` 状态继续兼容，不自动改写存储数据。
- **本周**：明确的本地周区间，遵循账号每周开始日设置。
- 当前任务常规筛选隐藏无开始／截止日期的历史待办，并保留必要祖先上下文。已有日程关联可以作为日历时间块继续访问。
- 项目和有效快捷视图保留未排期任务。文本节点可作为叶子记录标题、正文、标签和资源，也可包含子节点。TODO 任务承担完成状态、优先级、排期和四象限等执行语义。
- 新任务继承明确的筛选条件和日期上下文；清除日期同时移除开始与截止，不保留虚假的本周安排。

## 4. 导图

### TODO 任务与文本节点

数据节点分为「TODO 任务」和「文本节点」。文本节点可以独立记录说明、结论、参数或链接，子节点属于可选的组织方式。类型选择器、右键单项与批量转换、详情标题以及列表图标统一使用「文本节点」。分组是文本节点包含子节点时的一种用途。

同一个文本节点可同时保存正文和组织子节点，可处于叶子或中间层。纯结构组织、叶子文本记录、带正文的中间层组织均为支持的用法。TODO 任务也可以包含子节点。

文本节点的标题和正文采用内容样式，历史任务完成信息作为转换数据保留。隐藏已完成与完成统计按 TODO 任务计算。项目全图和仅按标签筛选的列表／导图可查到文本叶子节点。顶层 TODO 转为文本节点后保持普通节点身份，「转为项目」为单独操作。旧项目按既有身份读取。

### 点击、选择与编辑

普通单击默认选中任务并打开详情。右上角「任务交互设置 → 单击任务打开详情」可关闭自动打开，偏好随账号同步。关闭时单击仍选中任务；详情图标、选中工具条的「详情」和 ⌘／Ctrl + Enter 仍可主动打开。

详情已经打开时，普通点选其他任务直接切换内容。双击进入标题编辑；输入法组合输入期间不提前提交。点击完成图标、折叠按钮等节点控件只执行自身操作。拖动节点、多选与框选不自动打开详情。

| 操作 | 行为 |
| --- | --- |
| 空白处单击 | 清除选择、收起详情并保存已有文字草稿 |
| 空白处拖动 | 框选节点；松开后范围框消失，保留各节点选中标记 |
| ⌘／Ctrl 或 Shift + 点选 | 多选；详情收起，保留批量样式与右键操作 |
| ⌘／Ctrl + A | 选择当前图中已展开节点；编辑文字时只全选文字 |
| 双击节点 | 编辑标题；输入框宽度随文字更新 |
| Tab／Enter | 添加子任务／同级任务；项目根节点的 Enter 添加子任务 |
| Delete | 删除所选任务；项目删除仍经确认 |
| ⌘／Ctrl + Z、⇧ + ⌘／Ctrl + Z | 撤销、重做 |

### 画布与结构

双指或滚轮平移，捏合缩放；鼠标中键或右键可拖动画布。空闲时保持正常指针。右下角显示缩放百分比、缩放、回根节点、全图与画布配置；画布配置包含连线样式和本浏览器按账号保存的平移速度。右上角的任务点击设置与右下角的画布设置分别命名。

大图初次打开优先显示根节点附近，后续按账号和项目记住位置与缩放。只有明确的任务定位请求才重新居中目标，普通选中、备注保存、日期修改不移动画布。切回页面、字体加载和容器尺寸恢复后需要重新确认节点及连线几何，不能依赖手工刷新。

拖到节点中部表示挂为子任务；上下边缘表示同级前后插入；全局导图可拖到用户名根节点移至顶层。当前导图连线表达父子层级；跨分支 DAG 依赖尚无独立编辑交互。筛选强调当前工作时保留全局位置，不任意交换节点位置。

多选后拖动任意所选节点会整批移动，按原树顺序插入。父子同时选中时移动整条分支，保留内部层级。整批移动可一次撤销与重做。落点排除所选分支及其后代，并在提交前校验整批挂靠关系。

## 5. 列表与四象限

列表保持紧凑行结构。选择后大屏右侧停靠详情，小屏使用统一的底部详情。拖动时展示目标位置与层级提示：行中部关联、边缘排序，向左移出层级。中文新建、回车确认、空白取消与已有任务编辑采用一致的输入法规则。

四象限显示任意层级的任务，按重要和紧急两个维度组织。拖动到另一个象限改变优先级；点击打开详情，双击象限空白新建。常规每象限显示前 24 项；明确跳转定位到更后面的任务时额外显示目标，不因展示限量丢失定位。

## 6. 甘特图

任务树位于左侧，时间轴位于右侧；名称列可调宽，任务条与名称中心对齐。文本节点与项目保留树形位置，TODO 任务的排期显示为时间条。

- 拖整条平移；拖左右端分别修改开始／截止，按 5 分钟吸附。只设一端的单日任务，拖另一端不能无故改变原有时间。
- 行内空白拖出区间可排期；项目的未排期任务可从下方拖入时间轴。取消拖动不写入日期。
- 条色由优先级决定，完成态使用完成色；调整日期不能把未完成任务变为不同深浅的状态色。
- 触控板水平滑动按当前区间跨度翻页，吸收同一次手势的惯性，避免一次手势翻多页；拖条、调整名称列和输入时不触发翻页。
- 点击任务名称或进度条打开统一详情；右击名称、条或轨道打开该任务菜单。

## 7. 日历

日历按所选区间展示日、周或月。可查看任务开始／截止标记与关联日程；没有日期的项目任务保留在未排期区域。

月历单元格根据可用高度显示尽可能多的条目，剩余内容显示「还有 X 项」。点击后弹出当天全部条目的紧凑可滚动列表。点击任务打开详情，点击日期或独立日程查看对应日期。

点击日期空白创建当天任务，配置并确认后才写入。如果已有新建提示，再次点击任意空白只取消当前提示；下一次独立点击才在新位置开启创建。拖动已有条目可改期，取消新建不产生空任务。

任务条目提供右键任务菜单，包括日／周／月、当天展开列表和未排期区域。独立日程保持自身操作语义。

## 8. 统一任务详情

导图、甘特图、四象限、日历、当前任务与快捷视图使用同一 `TaskInspector` 内容。桌面默认以右上角非模态卡片承载；若会遮挡刚点选的分支，则在画布左侧打开，并为底部操作条留出空间，继续允许操作背景任务；列表大屏保留右侧紧凑停靠格式。移动端使用有遮罩的底部面板，但字段顺序和操作与桌面一致。

从上到下为：详情标题与保存状态、**View in**、置顶资源（若有）、祖先路径、任务标题／完成、日期／优先级、Workspace、相关资源、描述、子任务。底部固定「添加子任务」和「更多设置」；更多设置包含节点类型、标签、专注统计／入口、删除／恢复和创建时间，不再次打开第二套详情。

开始日期、截止日期、优先级并排为一行，手机上也保持三列。日期入口保留完整时间提示，清除操作放在日期弹层中；优先级入口显示 P0–P3 或待分级，完整含义在下拉选项中显示。不再单列状态徽标或「标为进行中」按钮。Workspace／Agent 移除重复教学小字，移除配置摘要和默认选择区，直接列出已创建 Workspace，点击只切换当前查看实例。Workspace 区域直接提供创建模板、创建 Workspace，Agent 区域提供新建 Agent；创建时汇集当前节点和祖先的模板／实例，独立 worktree 默认开启且与自定义目录互斥。相关资源不显示数量，也不再创建「资源 · N」快捷入口，只有置顶资源保留顶部快捷链接。

详情切换复用面板，不反复关闭再播放开场动效。切换后重置正文滚动和未提交的辅助输入状态，保存当前任务的标题／描述。关闭、点击空白、视图跳转、下拉关闭均提交文字草稿；旧保存完成后的关闭回调不能误关新选中的任务。保存失败时保留详情并显示错误。

手机打开详情只聚焦面板，不自动聚焦标题或弹键盘。正文到顶才能下拉收起，距离不足回弹；输入、文字选择、按钮操作、横向或多指手势不触发关闭。

节点级 Workspace 支持逐字段继承环境、仓库和 Agent 配置，可创建或复用 SSH/tmux、Docker 和 Kubernetes 环境，再向已有 tmux pane 投递文本。配置、实例快照、生命周期和操作细节记录在 [Workspace 配置与环境执行设计](WORKSPACE_DESIGN.md)。网页、PR、笔记及旧 tmux 链接统一显示为「相关资源」。

## 9. 跳转到视图

详情顶部明确标注「View in」，悬浮提示「在另一个视图中打开」，提供所属项目／任务分支的五个视图快捷入口。右击任务后，通过「跳转到视图」选择：

| 分组 | 行为 |
| --- | --- |
| 所属项目／任务分支 | 列表、导图、四象限、甘特图、日历；没有项目的独立任务使用自身根分支 |
| 当前任务 | 进入左侧全局当前任务工作区，默认甘特图；未排期目标临时使用列表定位 |
| 快捷视图 | 列出账号保存的快捷视图；跨项目、仅支持 TODO 任务等无有效目标的选项禁用 |

跳转不复制任务、不改任务的排期、状态和层级。离开前保存未失焦的文字草稿，再进入目标工作区，展开祖先、选中或高亮任务并滚动／居中。隐藏已完成偏好保持不变；明确定位可以临时展示该目标。修改筛选、时间区间或完成显示时清除临时定位。

快捷视图保留原有筛选和配置；时间画布不包含目标日期时在 URL 中临时改为目标附近的区间，不改写快捷视图定义。未排期任务跳往有限时间视图时使用列表，避免为显示而补写日期。文本节点和项目根可定位到列表与导图。

右键批量菜单中的跳转以被右击的任务为定位目标，不批量跳转；数据变更操作仍按已有多选集合执行。子菜单内容可滚动，位置避让窗口边缘；Esc 或点空白关闭。

## 10. 习惯、复盘与专注

习惯每项占一行，点击展开近期打卡热力记录，再点收起；同一时刻只展开一项。创建后可编辑，支持拖动排序与按提醒时间排序。每日多次目标保留 `已完成／目标` 数字，并按比例填充打卡标记；可设置多个时间槽，也可关闭提醒。

应用内习惯提示支持去打卡、延后与关闭本次，空闲时自动淡出；关闭当前提示不打卡、不关闭后续提醒。iPhone 原生通知的授权、排程与点击归属见移动端文档。

日报／周报最上方展示实际进展，自动列出本期完成的任务，并保留阶段进展文字。推进计划单独填写，按开始／截止日期带入本日或本周的任务。阻碍下方列出截至当天尚未完成的已排期任务，包含更早遗留项，可直接勾选完成并同步进入实际进展，计划中保留完成标记。默认每天 21:30、周日 20:00 提醒，可在设置调整。草稿随账号同步，完成复盘时保留当期任务列表与专注事实快照。

专注可关联任务，保留时长与中断记录。任务中的 tmux、Agent、Note 使用同一资源组件，按独立区域组织；终端权限以当前账号和服务器配置为边界。

## 11. 数据与交互验收

同步、导出／导入与离线编辑必须保留账号隔离、任务 ID 与历史记录。筛选、导航偏好和 UI 更新不得清空数据卷或浏览器数据库。Agent REST API／Swagger 文档属于外部操作入口，不能让页面跳转隐式修改任务。

| 场景 | 必须满足 |
| --- | --- |
| 导图点选／框选／多选／拖动 | 默认详情与开关生效，控件和手势不误触发；镜头、连线稳定 |
| 各视图打开与切换详情 | 同一内容结构，连续切换不丢草稿、不关闭新详情，不叠加另一套面板 |
| 项目五视图／当前任务／快捷视图跳转 | 目标可见，祖先展开，过滤与完成偏好可恢复，不改任务日期 |
| 远期／逾期／未排期／已完成／文本节点 | 明确各自的可达目的地，不能跳到空白画布后丢失任务 |
| 320／390 px 与移动键盘 | 工具栏和详情无页面横向溢出，打开详情不弹键盘，正文滚动和下拉正确 |
| 项目与习惯改动 | 创建、编辑、排序和删除反馈明确；取消不生成空内容 |
| 发布 | 独立临时实例回归；完整备份、保留回滚镜像；生产只读验证 |

主要实现：`TasksPage`、`TaskMenu`、`TaskInspector`、`TaskSheet`、`taskNavigation`、`useTaskTextDraft` 与各视图。后续改变本约定时同步更新本文与移动端文档。

## 12. Workspace 与多 Agent

任务和文本节点详情中的 Workspace 可关联命名配置并按父链继承。创建环境默认同时启动 Agent，生成可编辑、绑定当前节点的 Prompt。一个环境可添加多个 Agent。紧凑卡片打开独立对话面板，桌面左侧选择 Agent、窄屏顶部选择，消息编辑支持中文输入法。

ACP 对话流独立更新，工具与思考默认收起，阅读历史时保留位置。工具权限由用户在会话内回应。tmux 工作台默认展示连续的「终端会话」，可以直接操作原生 TUI；「工作记录」查看消息、状态和报告，历史整屏快照合并展示最近一份。完整终端与内嵌终端互斥连接；短暂断线自动重连原 pane，Esc 传给 TUI。中止本轮、停止 Agent、恢复已有会话和明确新开会话按各自含义执行。终端输出和投递成功不代表任务完成；执行报告写回实际任务描述并保留人工正文。完整对象、权限和恢复规则见 [Workspace 与 Agent 对话](WORKSPACE_AGENT_DESIGN.md)。
## 13. Task 标题链接（2026-11-24）

标题支持内联 `[显示文字](https://example.com)` 与直接书写的 HTTP/HTTPS URL；列表、导图、四象限、甘特和日历统一显示链接文字。编辑时保留原始语法，详情编辑框下显示可点击预览。导图按照显示文字计算节点尺寸，编辑期间按照输入原文实时扩展。

从网页复制包含链接的文字时，粘贴保留文字和链接目标；复制纯 URL 自动识别为链接，选中文字后粘贴 URL 可将所选文字变成链接。点击链接在新标签页打开，不触发 Task 详情、拖动或完成状态切换；点击其他部分仍按视图原有规则操作。标题不执行 HTML、脚本或本地文件链接，也不会自动请求目标网站来获取标题。


### 整日排期

任务菜单的「今天／明天／下周」和列表日期快捷键同时设置本地当天 00:00 开始、23:59 截止；单项与批量使用同一规则且可一次撤销。快速收集的纯日期（如 @今天）及日历／列表按日期创建任务也补齐当天开始时间。明确编辑开始或截止字段仍只更改所选端点，清除操作不重新填入另一端点。已保存的旧任务不会被批量改写。

Task 详情的 Workspace 区域提供创建入口、默认收起的当前／祖先模板管理列表，以及已有实例。空实例列表只显示「暂无 Workspace」。Agent 创建通过标签页选择模板新建或复用实例，工作目录显示完整路径，工作阶段由 Agent 根据 Task 和 Prompt 判断。集群配置位于个人设置的 SSH 服务器之后。详见 [Workspace 与 Agent](WORKSPACE_AGENT_DESIGN.md)。

## 多账号登录与切换（2026-11-26）

左下角「设置／用户名／同步」保持一行。打开设置后，账号区直接展示本浏览器已登录账号，
标出当前身份与管理员，点击另一账号立即切换。添加账号、退出单个账号和退出全部均在该区操作，
不再另设账号管理页面或侧栏切换图标；旧 `/accounts` 地址跳转到 `/settings#accounts`。
添加账号进入登录／注册表单，已有账号可返回；新账号仍需要邀请码。最多保存 10 个账号。

同一浏览器标签页共享当前身份。切换成功仍停留在设置页，显示新账号的设置；其他标签页同步身份并关闭原任务详情、
选择、菜单和终端。账号的任务、习惯、复盘、SSH／Kubernetes 配置、Workspace、Agent 和本地数据库仍分别隔离。
切换先停止旧同步、保存本地待持久化数据，再连接新账号；登录失败恢复原账号同步。
退出移除该账号在本浏览器的免密切换资格，保留本地数据与其他设备登录；需要联网完成退出。
这不是启动／停止 Agent：账号切换不终止后台 Agent，也不撤销其独立执行凭据。

本浏览器保存登录采用 HttpOnly Cookie，前端不保存密码或可复用 Token。localStorage 只保存当前身份元数据和跨标签页通知。
